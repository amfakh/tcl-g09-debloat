# TCL Smart TV Pro (device G09, product G09_4K_GB, Amlogic T5M, armeabi-v7a, 2 GB RAM), 2023
# Android 12 (Google TV), firmware STT2.230203.001.AS24, software V8-T800T02-LF1V157, used in Indonesia.
# Based on examples/tcl-g09-google-tv in github.com/Gathin23/cleanyourtv (same product and build).
#
# Apply:   tools/debloat.sh
# Undo:    tools/restore.sh
# Everything is DISABLED for user 0, never uninstalled. Comment out a line to keep that app.
#
# Stock launcher com.google.android.apps.tv.launcherx and the setup wizard
# com.google.android.tungsten.setupwraith stay enabled: there is no replacement launcher yet, and
# setupwraith owns a saved Wi-Fi network on this set (disabling it deletes that network).
# Never disable: com.tcl.tv (Live TV, HDMI playback), com.tcl.tvinput (HDMI and tuner inputs),
# com.tcl.suspension (Input menu), com.tcl.dashboard, com.tcl.autopair (remote pairing),
# com.tcl.systemserver (mic hotkeys), com.tcl.providers.config, com.tcl.globalkeyoverlay, Play Store,
# Play Services, the keyboards. com.tcl.factory.view is a factory package: never launch it.
# Firmware updates come through Play Services on this build, so com.tcl.ttvs can go.
# Already disabled before the first run: com.tcl.ocean.instructions, com.google.android.youtube.tvmusic.
# restore.sh leaves those two off.
